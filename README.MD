# Todo App

Учебный проект: TODO-приложение для управления списком задач с backend на FastAPI. Backend разрабатывается вручную; Codex используется как вспомогательный инструмент для обучения и разбора ошибок. Код от Codex копируется только тогда, когда он основан на уже написанном мной коде.  
Обучение проходило по 12-часовому видеоуроку Кирилла Македонского. Готовый frontend был клонирован с GitHub и запускается с помощью Node.js.
«Запускается с помощью Node.js» точнее, чем «frontend на Node.js»: Node.js обычно служит средой запуска инструментов frontend-проекта.
